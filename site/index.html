ARCHITECTURE

Engineered for Deterministic Execution

Three crisp mechanisms make AgentWiki the most reliable knowledge engine for autonomous coding agents.

01 / COMPILE

Git-Native Knowledge Graph

Store documentation in human-readable markdown inside .agentwiki/. AgentWiki parses frontmatter, extracts relational links, and builds an optimized SQLite database in milliseconds.

$ agentwiki compile → index.db
02 / SERVE

Zero-Config Local MCP Stdio

Runs as a standard I/O process compliant with the Model Context Protocol. Seamlessly works with Cursor, Claude Code, and Windsurf without network overhead or cloud tokens.

Transport: stdio / JSON-RPC 2.0
03 / REVIEW

Atomic Proposal Diffs

When agents discover architecture updates, they submit proposals via agentwiki_propose_diff. Review changes via the Obsidian CLI with confidence scores before accepting.

$ agentwiki review → git diff
PROTOCOL SPECIFICATION

Three High-Precision MCP Tools

AgentWiki provides a minimal, non-overlapping tool surface for AI models. Click any tool below to inspect its schema and JSON-RPC payload.

agentwiki_search(query, limit)
Sub-5ms BM25 full-text search returning relevant documents with token metrics.
READ-ONLY
// Example tool call from Claude Code
{
  "name": "agentwiki_search",
  "arguments": {
    "query": "authentication token rotation",
    "limit": 3
  }
}
agentwiki_read(slug, format)
Fetches structured document content in markdown, JSON entities, or sub-400-token summary.
READ-ONLY
// Example tool call from Cursor
{
  "name": "agentwiki_read",
  "arguments": {
    "slug": "architecture/auth-invariants",
    "format": "json_summary"
  }
}
agentwiki_propose_diff(slug, diff, rationale)
Allows agents to safely propose updates without directly overwriting git files.
ATOMIC PROPOSAL
// Agent submits architectural proposal
{
  "name": "agentwiki_propose_diff",
  "arguments": {
    "slug": "api/v2-endpoints",
    "rationale": "Updated rate limit headers to RFC 7807 specification",
    "confidence": 0.96
  }
}
QUICKSTART

Up and Running in 60 Seconds

Zero installation footprint. Compatible with all modern LLM IDEs and terminals.

1

Initialize AgentWiki in your repository

Creates the .agentwiki/ directory with starter documentation templates and schema validation.

$ npx @hamidshahid/agentwiki init
2

Compile the knowledge graph

Builds the local SQLite full-text search index and verifies Markdown frontmatter integrity.

$ npx @hamidshahid/agentwiki compile
3

Register the MCP Server in Cursor or Claude Code

Add the following block to your .cursor/mcp.json or Claude Code configuration:

{
  "mcpServers": {
    "agentwiki": {
      "command": "npx",
      "args": ["-y", "@hamidshahid/agentwiki", "serve"]
    }
  }
}
